# Geospatial API & MongoDB Application

A modular REST API built with Node.js, Express, and MongoDB to fetch and store geospatial data from the Open-Meteo public API.

## Installation & Setup

1. **Install packages:**
   ```bash
   npm i dotenv express mongoose express-rate-limit

2. **Environment setup:**
PORT=3000
MONGODB_URI=mongodb://127.0.0.1:27017/geoDataDB

3. **Start the App**
npm start
